# Correção Hello World - Zarcovi RPG Banco

Use este pacote para substituir o Hello World.

## Faça assim

1. Extraia o ZIP.
2. No GitHub, apague o arquivo `index.html` solto na raiz, se existir.
3. Envie estes arquivos para o repositório.
4. Confirme que existe `public/index.html`.
5. Faça commit.
6. No Cloudflare Pages, use:

Build command:
npm run build

Build output directory:
public

Deploy command:
npm run build

## Importante

O site certo está em:

public/index.html

Se aparecer Hello World, o Cloudflare está usando outro arquivo ou deploy antigo.
